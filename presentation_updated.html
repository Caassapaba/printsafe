PRINTSAFE

Estufa Inteligente para Impressão 3D

Sistema completo de monitoramento em tempo real com sensores de alta precisão, display LCD 20x4, interface web profissional com gráficos Chart.js, controle via encoder rotativo e logging em SD Card.

🚀 Ver Demonstração 📊 Especificações

Recursos Principais

🌡️

Monitoramento Completo

4 sensores simultâneos:
• DHT22 - Temperatura e Umidade
• LDR - Luminosidade ambiente
• MAX4466 - Nível de ruído
Leituras a cada 1 segundo com alta precisão

📺

Display LCD 20x4

Interface local intuitiva:
• Valores em tempo real
• Faixas ideais por material
• Status colorido (OK/ATENÇÃO/CRÍTICO)
• Atualização a cada 1 segundo

🎛️

Encoder Rotativo EC11

Controle físico:
• Girar para navegar entre materiais
• Pressionar para confirmar
• Feedback visual no LCD
• Timeout automático de 10s

🌐

Interface Web PRO

Dashboard profissional:
• Design cyberpunk (cyan/verde neon)
• Tema da estufa inteligente
• Animações suaves
• Responsivo (mobile/desktop)

📊

Gráficos Chart.js

Histórico em tempo real:
• 4 linhas simultâneas
• Últimos 30 pontos (~1 minuto)
• Interativo (hover, legendas clicáveis)
• Atualização automática a cada 2s

💾

Logging em SD Card

Armazenamento robusto:
• Modo SDMMC (4x mais rápido)
• Logs CSV por data
• Download via web
• Histórico ilimitado

📡

WiFi Dual Mode

Conectividade flexível:
• Modo AP (Access Point)
• Modo Station (conectar à rede)
• Fallback automático
• Configuração via web

🎯

4 Perfis de Material

Faixas ideais calibradas:
• PLA: 18-28°C, 40-60%
• PETG: 20-30°C, 30-50%
• ABS: 22-32°C, 20-40%
• RESINA: 20-25°C, 40-60%

Especificações Técnicas

Microcontrolador
ESP32-S3 WROOM1
Sensor Temp/Umid
DHT22 (GPIO 17)
Sensor Luz
LDR (GPIO 4)
Sensor Som
MAX4466 (GPIO 8)
Display
LCD I2C 20x4 (0x27)
I2C Pinos
SDA: 10, SCL: 13
Encoder
EC11 5-pin (GPIO 5,6,7)
SD Card
SDMMC 1-bit (39,38,40)
WiFi
802.11 b/g/n
Alimentação
5V USB-C
Consumo
~300mA típico
Taxa de Atualização
1Hz sensores / 0.5Hz web
